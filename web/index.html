Getting Started

When loading fresh firmware, the device starts in demo mode:

  1. Wait for the initial animation to complete
  2. Press the Power button to exit demo mode
  3. Navigate using the directional buttons

Keyboard Controls

  • Arrow Keys: Move in corresponding direction
  • M: Menu button
  • A: Action button
  • P: Power button
  • U: Mute button

Touch Controls

When the emulator is running, use the on-screen buttons that correspond to the physical buttons on the device.

Saving Progress

Your game progress is automatically saved every second, but for guaranteed saving:

  1. Press the Power button to put the device to sleep
  2. This triggers the firmware's built-in save function
  3. Use "Download Backup Copy" in the configuration screen to backup your save

Welcome to Emiu2!

This emulator lets you play Miuchiz handheld devices right in your browser.

Quick Start Guide:

  1. Configuration: Select your firmware from the options
  2. Starting: Fresh firmware shows a demo - press Power to exit it
  3. Controls: Use arrow keys on keyboard or on-screen buttons
